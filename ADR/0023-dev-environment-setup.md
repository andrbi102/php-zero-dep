# ADR-0023: راه‌اندازی محیط توسعهٔ PHP درون skill

- وضعیت: Accepted
- تاریخ: 2026-11-25
- تصمیم‌گیرنده: Tooling Specialist (T-046-01)
- approved_by: Council Architect (T-000-01)

## Context (زمینه)
هر مکالمهٔ توسعهٔ PHP در sandbox نیاز به راه‌اندازی محیط دارد (PHP،
Composer، دیتابیس، سرور توسعه). بدون یک سند مرجع، هر بار از نو کشف می‌شد و
ناسازگاری ایجاد می‌کرد. کاربر سند جامع `PHP_DEV_ENV_SETUP.md` را بارگذاری
کرد تا درون skill گنجانده شود.

## Decision (تصمیم)
سند `PHP_DEV_ENV_SETUP.md` (تأمین‌شده توسط کاربر) در `docs/dev-environment/`
گنجانده شد با نمایهٔ `00-index.md`. سند مستقل از نسخه است: روش کشف آخرین
نسخهٔ PHP (از `static-php-cli/gnu-bulk`) را آموزش می‌دهد، نه نسخهٔ هاردکد.
مسیر اصلی (گام‌های ۱-۵) + مسیرهای پیشرفته (بیلد از سورس، nginx+PHP-FPM،
benchmark، تونل زنده، بازبینی بصری).

## Consequences (پیامدها)
+ راه‌اندازی قابل‌تکرار در هر مکالمه.
+ صداقت محدودیت (مستند می‌کند چه‌چیز در sandbox ممکن نیست).
+ dogfood: مهارت خودش با همین زنجیره ساخته شد (PHP 8.4 استاتیک برای تست‌ها).
− سند طولانی (~۷۰۰ خط)؛ برای شروع سریع، نمایهٔ `00-index.md` کافی است.
− برخی مسیرهای پیشرفته (nginx از سورس) زمان‌بر؛ فقط با درخواست صریح.
