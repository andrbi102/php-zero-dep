# مهندسی معکوس کد (REA)

خروجی REA برای «درک الگو» استفاده می‌شود، نه کپی مستقیم.
ابزارها: **disrobe** (دی‌کامپایلر)، **mago-reflection** (carthage-software/mago —
بازرسی و تحلیل کد PHP + AST، پارسر zero-dependency به Rust).
رویکرد: ابتدا ساختار (کلاس‌ها، وابستگی‌ها، روت‌ها) مستند شود، بعد
الگوهای قابل‌بازآفرینی استخراج شوند.

### ✅ Checklist

- [ ] مجوز و کپی‌رایت مخزن مبدأ بررسی شده
- [ ] خروجی = مستند الگو، نه کپی کد
- [ ] پیش از بازآفرینی، ADR ثبت شود

### ❌ Anti-patterns
- کپی کد با لایسنس ناسازگار MIT
- کپی پیاده‌سازی رمزنگاری بدون بازبینی متخصص
