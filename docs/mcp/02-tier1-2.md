# ابزارهای Tier-1 و Tier-2

Tier-1 (پیش‌فرض فعال): Context7 (مستندات نسخه‌محور).
Tier-2 (با نیاز و مجوز صریح کاربر): Playwright MCP (تست مرورگر — فقط dev)،
ابزارهای تحلیل کد (PhpCodeArcheology MCP)، VibeShell به‌عنوان سرور MCP
PHP. MCP ابزار توسعه است نه وابستگی runtime: پروسه‌اش جدا است و کد
PHP تولیدشده هیچ import از MCP ندارد.

### ✅ Checklist

- [ ] هر ابزار Tier-2 با مجوز کاربر
- [ ] سرور MCP در فرایند جداگانه
- [ ] هیچ فراخوانی MCP در مسیر production

### ❌ Anti-patterns
- پایپ‌لاین production وابسته به MCP
