# محدودیت‌های MCP

Local نیازمند Node.js (npx)؛ Remote نیازمند شبکه (و کلید برای
نرخ معقول)؛ context window محدود است — پاسخ‌های query-docs را
خلاصه و هدفمند بخواهید. MCP «ابزار توسعه» است نه وابستگی runtime
(قید ۱۱ بخش ۱۲): نبود آن هیچ قابلیت production را نمی‌شکند، فقط
سرعت/دقت مشورت مستندات را کم می‌کند.
