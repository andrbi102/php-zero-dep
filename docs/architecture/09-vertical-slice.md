# Vertical Slice — سازمان‌دهی بر اساس Feature

سازمان‌دهی کد بر اساس قابلیت (Feature) نه لایه فنی؛ هر Slice کل
مسیر یک قابلیت را دارد. توجه صداقت‌محور SPEC: مرجع فریمورکی قابل‌تأیید
برای PHP خالص ندارد (دستی از اصول). هم‌پوشانی با CQRS: هر Slice می‌تواند
command/query خودش را با `scaffolds/command-bus.php` و `query-bus.php` داشته باشد.

### ✅ Checklist

- [ ] هر Slice مستقل تست و حذف‌شدنی است
- [ ] اشتراک فقط از طریق Domain مشترک
- [ ] Slice از ساختار لایه‌ای کلان پروژه پیروی می‌کند

### ❌ Anti-patterns
- Slice که به داخل Slice دیگر نفوذ می‌کند
- لایه فنی مشترک بزرگ که Sliceها را به هم گره می‌زند
