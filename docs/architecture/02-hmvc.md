# HMVC — MVC سلسله‌مراتبی

ماژول‌ها می‌توانند خروجی یکدیگر را درخواست کنند — اما فقط از مسیر
**Dispatcher** (`scaffolds/hmvc-dispatcher.php`)، هرگز با `new Controller()`
مستقیم. مرجع: Trongate (ساختار admin module)، DynaPort X.

مزیت برای ایجنت: هر ماژول قابل تست/استقرار مستقل است و دیسپچر نقطه
واحد اعتبارسنجی و لاگ فراخوانی‌های بین‌ماژولی است.

### ✅ Checklist

- [ ] همه فراخوانی بین‌ماژولی از HmvcDispatcher
- [ ] نام action با الگوی anchored اعتبارسنجی می‌شود
- [ ] ماژول هیچ فرضی از حالت داخلی ماژول دیگر ندارد

### ❌ Anti-patterns
- new SomeController() از ماژول دیگر
- اشتراک متغیر سراسری بین ماژول‌ها
