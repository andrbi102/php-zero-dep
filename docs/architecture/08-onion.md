# Onion — لایه‌های متحدالمرکز

هم‌پوشانی عمدی با Hexagonal: وابستگی‌ها فقط به سمت مرکز (Domain) هستند.
هر لایه فقط لایه داخلی‌تر را می‌بیند. پیاده‌سازی با `final class` +
`interface` — بدون هیچ بسته بیرونی. برای مهارت: onion middleware در
`scaffolds/pipeline.php` الگوی مرجعِ لایه‌بندی رفتار است.

### ✅ Checklist

- [ ] جهت وابستگی فقط به داخل
- [ ] هر لایه با interface مرز می‌خورد
- [ ] تست لایه بیرونی با جعل interface داخلی

### ❌ Anti-patterns
- ارجاع لایه داخلی به کلاس لایه بیرونی
