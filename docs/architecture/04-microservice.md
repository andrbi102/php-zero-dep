# Microservice — سرویس‌های کوچک مستقل

هر سرویس stateless است و دیتابیس خودش را دارد؛ ارتباط با HTTP/JSON
از طریق `scaffolds/http-client.php` (timeout + retry).
هشدار واقع‌بینانه: در PHP بدون orchestrator، پیچیدژی استقرار چند سرویس
معمولاً بر ارزش آن می‌چربد — فقط با توجیه واقعی (مرجع وب‌سرویس: webrium/core).

### ✅ Checklist

- [ ] هر سرویس دیتابیس جداگانه دارد
- [ ] تمام تماس‌های خروجی timeout و retry دارند
- [ ] قرارداد سرویس مستند و نسخه‌بندی‌شده است

### ❌ Anti-patterns
- دیتابیس مشترک بین سرویس‌ها
- زنجیره تماس هم‌زمان عمیق (latency ضربدرمی‌شود)
