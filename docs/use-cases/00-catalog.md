# کاتالوگ کاربردها — ۲۰ دسته، ~۳۶۰ کاربرد

> نسخه مهارت: **0.0.2** | ADR متناظر: [0025](../../ADR/0025-use-case-taxonomy.md)
>
> **چرا این سند:** در v0.0.۱، `docs/use-cases/` شش کاربرد عمودی داشت
> (website، ecommerce، REST، CMS، CLI، blog). در v0.0.۲، یک **تاکسونومی
> کامل ۲۰-دسته‌ای** با ~۳۶۰ کاربرد مشخص افزوده شد تا ایجنت برای هر درخواست
> کاربری، بداند دقیقاً کدام دسته و کدام زیرمجموعه است و کدام scaffolds
> لازم است. هر دسته یک فایل جداگانه (`07-…` تا `26-…`) با checklist و
> anti-pattern دارد.
>
> **نحوهٔ استفاده:** درخواست کاربر را به جدول زیر نگاشت کن → فایل دسته را
> بخوان → scaffolds لازم را از `scaffolds/` بردار. اگر کاربر دو دسته را
> ترکیب کرد (مثلاً «فروشگاه با انجمن»)، هر دو فایل را بخوان و فازهای مشترک
> را در F2 ادغام کن.

## روابط افقی

برخی کاربردها **horizontal** هستند (در چند دسته تکرار می‌شوند چون زیرساختی‌اند):

- **احراز هویت / امضای دیجیتال / ثبت‌نام آنلاین / مدیریت کاربران**: `12.11`, `12.17`, `14.10`, `14.11`, `14.12`, `14.13` — همگی از `scaffolds/session.php`, `scaffolds/csrf.php`, `scaffolds/crypto.php` و یک Auth Specialist (T-024). یک‌بار بساز، در همهٔ دسته‌ها بازاستفاده کن.
- **پرداخت / درگاه / سبد خرید / کد تخفیف**: `3.x`, `4.1-4.2` — از `scaffolds/http-client.php` (مستندات درگاه از MCP)، `validator.php`، `crypto.php`. idempotency سفارش الزامی.
- **رزرو / نوبت / تقویم**: `8.1-8.6`, `10.2`, `20.4` — الگوی slot با قفل رکوردی (SELECT … FOR UPDATE یا token یک‌بارمصرف).
- **آپلود فایل / رسانه**: `7.x`, `12.4`, `16.1-16.2`, `17.9` — Upload Security Specialist (T-031): MIME sniff، rename، ذخیره بیرون webroot.
