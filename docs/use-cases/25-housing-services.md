# کاربرد: مسکن و خدمات منزل

> نسخه مهارت: **0.0.2** | کد دسته: **۱۹** | کاتالوگ: [`00-catalog.md`](00-catalog.md)
> ADR: [0025](../../ADR/0025-use-case-taxonomy.md) | پروفایل پیشنهادی: **solo→full**

## مرور

دستهٔ مسکن/خدمات منزل، کاربردهای خانه/خدمات: اجاره/خرید خانه، هم‌خانه، خدمات
منزل، تعمیرات، نظافت، باغبانی، اسباب‌کشی، خدمات فنی، درخواست متخصص. واحد
دادهٔ «ملک/درخواست خدمت» است؛ تمرکز روی تطبیق عرضه/تقاضا و اعتماد است.

## الگوی مشترک

- **اعتماد:** تأیید متخصص (مجوز فنی 19.9، رتبه پس از کار)؛ عکس کار انجام‌شده؛
  رأی اعتماد محلی.
- **قیمت‌گذاری:** پیش‌فاکتور با جزئیات (نه قیمت مبهم)؛ پرداخت مقاطعی
  (escrow) برای کارهای بزرگ (اسباب‌کشی 19.8).
- **رزرو نوبت:** slot با قفل رکوردی (8.3 الگو)؛ یادآوری.
- **تماس محافظت‌شده:** شماره واقعی مخفی (9.2 الگو)؛ anti-scraping.
- **گواه:** کار انجام‌شده با عکس + امضای دیجیتال (در صورت نیاز قانونی).
- **مدیریت تیم:** برای نظافت/اسباب‌کشی (با چند نفر)، تخصیص تیم + زمان‌بندی.

## ✅ Checklist

- [ ] تأیید متخصص (مجوز/رتبه)
- [ ] پیش‌فاکتور با جزئیات + escrow برای کار بزرگ
- [ ] رزرو با قفل slot + یادآوری
- [ ] تماس محافظت‌شده
- [ ] عکس قبل/بعد کار
- [ ] rate limit روی درخواست

## ❌ Anti-patterns

- قیمت مبهم (اختلاف بعدی)
- بدون escrow (عدم پرداخت/کیفیت)
- شماره مستقیم متخصص (scraping)
- بدون عکس کار (اختلاف کیفیت)
