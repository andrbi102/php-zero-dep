# کاربرد: آگهی، املاک، خودرو و بازار کار

> نسخه مهارت: **0.0.2** | کد دسته: **۹** | کاتالوگ: [`00-catalog.md`](00-catalog.md)
> ADR: [0025](../../ADR/0025-use-case-taxonomy.md) | پروفایل پیشنهادی: **solo→full**

## مرور

دستهٔ آگهی/بازار کار، کاربردهای فهرست‌بندی کالا/خدمت/شغل: املاک، خودرو،
آگهی طبقه‌بندی، کاریابی، فریلنسری، مناقصه. واحد دادهٔ «آگهی/رزومه/پروژه» است؛
چالش اصلی جستجو/فیلتر و اعتبارسنجی کاربر است.

## الگوی مشترک

- **جستجو/فیلتر:** پارامترها با `validator.php` اعتبارسنجی؛ کوئری با
  Prepared (هرگز چسباندن SQL)؛ فیلترهای پراستفاده با cache.
- **اعتبارسنجی کاربر:** تأیید ایمیل/تلفن (کد یک‌بارمصرف)؛ رتبه‌بندی فقط
  پس از معامله تأییدشده.
- **تماس محافظت‌شده:** شماره تماس واقعی مخفی؛ سیستم واسط (فرم/چت)؛ anti-scraping.
- **مناقصه مهر و موم:** پیشنهادها رمزنگاری‌شده (`crypto.php`) تا زمان بازگشایی؛
  بازگشایی با کلید بعد از deadline.
- **رزومه/نمونه‌کار:** خروجی با URL امضاشده (anti-hotlink)؛ PDF با ext-dom.

## ✅ Checklist

- [ ] فیلترها اعتبارسنجی + Prepared
- [ ] اعتبارسنجی کاربر (کد یک‌بارمصرف)
- [ ] تماس محافظت‌شده (نه شماره مستقیم)
- [ ] پیشنهاد مناقصه رمزنگاری‌شده تا بازگشایی
- [ ] رتبه‌بندی فقط پس از معامله تأییدشده
- [ ] rate limit روی جستجو/درخواست

## ❌ Anti-patterns

- شماره تماس مستقیم در آگهی (scraping/اسپم)
- SQL چسبانده برای فیلتر (tSQLi)
- رتبه‌بندی بدون تأیید معامله (نظامی)
