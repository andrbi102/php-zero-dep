# کاربرد: محلی، اجتماعی و مشارکتی

> نسخه مهارت: **0.0.2** | کد دسته: **۱۸** | کاتالوگ: [`00-catalog.md`](00-catalog.md)
> ADR: [0025](../../ADR/0025-use-case-taxonomy.md) | پروفایل پیشنهادی: **solo**

## مرور

دستهٔ محلی/اجتماعی، کاربردهای مقیاس محله/شهر: سایت محلی، انجمن محله، خدمات
همسایگی، داوطلبی، خیریه، حمایت مالی جمعی، رویداد محلی، شبکه کمک‌رسانی، گزارش
مشکلات شهری. واحد دادهٔ «رویداد/گزارش/کمک» است؛ تمرکز روی مشارکت آسان است.

## الگوی مشترک

- **geo:** مکان در گزارش/رویداد (lat/lng یا محله)؛ نقشه با embed (OSM)؛
  فیلتر بر اساس نزدیکی.
- **شفافیت (18.5/18.6):** هر کمک/مبلغ در صورت‌حساب عمومی قابل‌مشاهده؛
  ردگیری وجه؛ نه ناشناس‌سازی کامل (حساب‌دهی).
- **گواه داوطلب (18.4):** ساعت داوطلبی ثبت + گواه امضاشده (Ed25519) قابل
  راستی‌آزمایی.
- **اعتماد محلی:** تأیید ساکن (کد پستی/تلفن)؛ رتبه‌بندی پس از تعامل.
- **گزارش شهری (18.9):** وضعیت (ثبت/در دست اقدام/حل)؛ رأی‌دهی برای اولویت؛
  عکس با آپلود امن.
- **مدیریت آسان:** فرم کوتاه + ثبت سریع (سد مشارکت پایین).

## ✅ Checklist

- [ ] geo با embed (نه API پولی بدون نیاز)
- [ ] شفافیت مالی در خیریه/جمعی
- [ ] گواه داوطلب امضاشده
- [ ] تأیید ساکن برای اعتماد محلی
- [ ] گزارش شهری با وضعیت + رأی
- [ ] فرم کوتاه (سد پایین)

## ❌ Anti-patterns

- خیریه بدون صورت‌حساب شفاف
- گواه داوطلب بدون امضا (قابل جعل)
- فرم طولانی (سد مشارکت بالا)
- گزارش بدون پیگیری وضعیت (کاربر ناامید)
