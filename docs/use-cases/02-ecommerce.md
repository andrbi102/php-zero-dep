# کاربرد: فروشگاه اینترنتی

مرجع کامل PHP خالص: **Whisker Cart** (فروشگاه کامل + MySQL) و
**QuadCore Store** (ecommerce-project-s1). اجزای بحرانی: سبد خرید در
نشست، قیمت‌گذاری سمت سرور (هرگز از کلاینت)، پرداخت با درگاه +
verify سمت سرور، idempotency برای سفارش، UPSERT موجودی با تراکنش.
CQRS برای ستون سفارش/کاتالوگ نامتقارن توجیه‌پذیر است.
