# کاربرد: نمایشگاه، موزه و گالری مجازی

> نسخه مهارت: **0.0.2** | کد دسته: **۱۷** | کاتالوگ: [`00-catalog.md`](00-catalog.md)
> ADR: [0025](../../ADR/0025-use-case-taxonomy.md) | پروفایل پیشنهادی: **solo**

## مرور

دستهٔ گالری مجازی، کاربردهای نمایش آثار هنری/موزه‌ای آنلاین: نمایشگاه، موزه،
گالری، حراج هنری، فروش آثار، پورتفولیو هنری، تور مجازی، آرشیو تصویری.
واحد دادهٔ «اثر/مجموعه» است؛ تمرکز روی نمایش باکیفیت و حفاظت تصویر است.

## الگوی مشترک

- **تصویر باکیفیت:** نسخه‌های multi-resolution (با ext-gd اگر موجود)؛
  thumbnail + بزرگ؛ lazy load؛ URL امضاشده HMAC (anti-hotlink).
- **حفاظت تصویر:** watermark با ext-gd (نامخراب)؛ disable right-click (سمت
  کلاینت — فقط بازدارنده، نه تضمین)؛ URL امضاشده با انقضا کوتاه.
- **گواه اصالت (17.4/17.5):** امضای دیجیتال Ed25519 از اثر + مالک؛ قابل
  راستی‌آزمایی مستقل.
- **تور مجازی:** پانوراما با embed (Pannellum/marzipano — سمت کلاینت)؛ PHP
  فقط نقطه/مسیر/متادیتا.
- **جستجو:** متادیتا (هنرمند، دوره، تکنیک، تگ)؛ فیلتر ترکیبی؛ cache کوئری پراستفاده.

## ✅ Checklist

- [ ] تصویر multi-resolution + lazy load
- [ ] URL امضاشده HMAC با انقضا (anti-hotlink)
- [ ] watermark نامخراب
- [ ] گواه اصالت امضاشده (Ed25519) برای حراج/فروش
- [ ] جستجوی متادیتا با cache
- [ ] دسترس‌پذیری: alt text برای هر اثر

## ❌ Anti-patterns

- تصویر اصلی بدون watermark/امضا (سرقت آسان)
- URL تصویر عمومی بدون انقضا (hotlink)
- بدون alt text (دسترس‌پذیری)
- تور سنگین سمت سرور (کند)
