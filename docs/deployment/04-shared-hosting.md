# هاست اشتراکی

محدودیت‌ها: بدون CLI، memory_limit پایین، `.htaccess` تنها اهرم.
پیامدها: migration از مرورگر (db-migrate.php با توکن env)؛ بدون
artisan-like ابزار خط فرمان؛ OPcache اغلب فعال است؛ لاگ در error_log
هاست. همه قابلیت‌های مهارت با همین محدودیت‌ها کار می‌کنند — این
فلسفه صفر وابستگی است.

### ✅ Checklist

- [ ] migration وب‌محور محافظت‌شده
- [ ] حداکثر حافظه در طراحی لحاظ شود
- [ ] .htaccess شامل هدرهای امنیتی

### ❌ Anti-patterns
- اتکا به SSH/CLI که کاربر ندارد
- ini_set برای رفع محدودیت حافظه
