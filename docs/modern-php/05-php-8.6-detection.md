# PHP 8.6 و تشخیص نسخه

PHP 8.6 (نوامبر ۲۰۲۶): Partial Function Application، کلاس Duration،
Polling API، تابع clamp(). دوره تثبیت است — پس از تثبیت و با تأیید صریح
به baseline اضافه شود. الگوی guard در بوت‌استرپ:

```php
if (version_compare(PHP_VERSION, '8.3.0', '<')) {
    http_response_code(500);
    exit('PHP 8.3+ required');
}
```
