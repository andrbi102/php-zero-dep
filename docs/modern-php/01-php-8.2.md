# PHP 8.2 — Readonly Classes و DNF Types

Readonly classes: تمامی propertyها readonly — عالی برای DTO و Value
Object (`readonly final class Money { public function __construct(public int $cents) {} }`).
DNF types: `(A&B)|null` برای intersection اختیاری.
توجه: PHP 8.2 در ۳۱ دسامبر ۲۰۲۶ EOL می‌شود — baseline پروژه جدید 8.3 است.

### ✅ Checklist

- [ ] DTO/ValueObject به‌صورت readonly class
- [ ] property hooks (8.4) با readonly ناسازگارند — اینجا مفید است

### ❌ Anti-patterns
- readonly برای Entity با تغییر وضعیت
- DNF به‌جای union ساده بدون نیاز
