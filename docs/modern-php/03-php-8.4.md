# PHP 8.4 — Property Hooks و Asymmetric Visibility

Property hooks: منطق get/set داخل property — با validation داخلی.
Asymmetric visibility: `public private(set) string $name` — خواندن عمومی،
نوشتن خصوصی. ⚠️ هشدار مهم: hooks با readonly ناسازگارند — انتخاب صریح
بین readonly class و hooked property. استفاده فقط با تأیید صریح
پروفایل پروژه (قاعده بخش ۹ SPEC).

### ✅ Checklist

- [ ] انتخاب readonly یا hooks با ADR
- [ ] private(set) برای state داخلی aggregate

### ❌ Anti-patterns
- ترکیب property hook با readonly (خطا)
- استفاده 8.4 بدون phpversion() guard
