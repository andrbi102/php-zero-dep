# PHP 8.5 — Pipe Operator

`mixed |> callable` — مقدار سمت چپ به callable سمت راست منتقل می‌شود:
`$slug = $title |> 'trim' |> 'strtolower' |> fn($s) => str_replace(' ', '-', $s);`
مرجع Pipe-native: **stann/stream** (توابع lazy و curried، صفر وابستگی)،
**Relay** (JustSteveKing — Fiber-native، حداقل‌وابستگی ext-curl+ext-mbstring،
نصب از VCS). استفاده فقط با تأیید صریح.
