# پیمایش BFS و DFS

BFS: کوتاه‌ترین مسیر بدون وزن، سطح‌به‌سطح — با صف اشاره‌گری.
DFS: پیمایش عمقی با پشته صریح (نه بازگشت عمیق — stack overflow)؛
کاربرد: تشخیص چرخه (state 1/2)، مرتب‌سازی توپولوژیک.
هر دو در `scaffolds/graph.php` آماده و در `examples/07` تست شده‌اند.
