# نقشه ذهنی مدل‌ها

مدل‌ها = گره‌ها، روابط = یال‌ها، وزن = قدرت رابطه (تعداد ارجاع FK).
ساخت: گراف از روی شِما (Schema Designer T-020)؛ پیمایش BFS برای
«همسایگی مفهومی»؛ خروجی برای مصورسازی. کاربرد ایجنت: درک سریع
داده‌های پروژه برای تولید کوئری/فرم درست (Mind Map Specialist T-044).

### ✅ Checklist

- [ ] مدل‌سازی از روی شِمای واقعی نه حدس
- [ ] وزن یال معنادار و مستند
- [ ] خروجی استاندارد (بخش 04)

### ❌ Anti-patterns
- گراف کامل همه‌به‌همه بدون وزن
