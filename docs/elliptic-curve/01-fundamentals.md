# مبانی رمزنگاری منحنی بیضوی

| مفهوم | توضیح | کاربرد PHP |
|--------|-------|------------|
| Curve25519 | منحنی مدرن ECDH | sodium_crypto_box (X25519) |
| Ed25519 | امضای دیجیتال | sodium_crypto_sign |
| P-256/P-384 | منحنی NIST | openssl |

قاعده مطلق: پیاده‌سازی منحنی بیضوی از صفر در production ممنوع —
از primitivهای آماده هسته (sodium/openssl) استفاده کنید.

### ✅ Checklist

- [ ] انتخاب منحنی با ADR مستند
- [ ] کلیدها هرگز در لاگ چاپ نمی‌شوند
- [ ] طول کلید با ثابت‌های رسمی بررسی می‌شود

### ❌ Anti-patterns
- پیاده‌سازی ریاضی منحنی از صفر
- کلید در فایل تنظیمات repo-commit شده
