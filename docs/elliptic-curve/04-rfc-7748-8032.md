# RFC 7748 و RFC 8032

**RFC 7748**: مشخصات Curve25519 و X25519 (توافق کلید ECDH).
**RFC 8032**: مشخصات Ed25519/EdDSA (امضای دیجیتال).
این دو RFC مرجع تطابق پیاده‌سازی‌اند: هر پیاده‌سازی یا fallback باید
vectorهای تست رسمی RFC را پاس کند (نمونه در `examples/` و
`tests/security-audit.php`).

### ✅ Checklist

- [ ] تست‌های vector رسمی RFC پاس می‌شوند
- [ ] پیاده‌سازی جایگزین، مرجع RFC خود را در PHPDoc ذکر می‌کند

### ❌ Anti-patterns
- تولید تست شخصی بدون ارجاع به vector رسمی
