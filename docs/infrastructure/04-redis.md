# Redis — ext-redis یا فایل

اگر ext-redis از پیش نصب است: استفاده مجاز (افزونه مجاز در صورت
وجود). در غیر این صورت: کش فایل‌محور دست‌نویس `scaffolds/cache.php`
(نه نصب predis با Composer — آن فقط در dev مجاز). انتخاب با ADR و
چون رابط کش مهارت generic است، تعویض بعدی کم‌هزینه است.

### ✅ Checklist

- [ ] رابط کش مستقل از پیاده‌سازی
- [ ] قفل stampede در هر دو حالت
- [ ] TTL برای همه کلیدها

### ❌ Anti-patterns
- نصب predis در runtime
- کش بدون انقضا برای داده‌ای که تغییر می‌کند
