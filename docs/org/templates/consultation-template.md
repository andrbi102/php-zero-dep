# مشورت C-002 — انتخاب سازوکار کش برای هاست اشتراکی

**C1 درخواست (Requester):** Core Developer (T-048) — ۲۰۲۶-۱۱-۲۵
**C2 Consultant:** Cache Specialist (T-036)

**C3 تحلیل:** هاست ext-redis ندارد؛ گزینه‌ها: کش فایلی (scaffolds/cache.php)
یا APCu (نصب نیست). کش فایلی با TTL و قفل اتمی برای بار این پروژه کافی است.

**C4 بررسی ریسک:** ریسک فایل: مسابقه نوشتن (mitigated: قفل flock)؛
ریسک رشد دیسک (mitigated: سقف اندازه + پاکسازی TTL در هر write).

**C5 تصمیم:** کش فایلی با سقف ۲۵۶MB و پاکسازی تنبل؛ ثبت محدودیت
«کش فایلی، نه Redis» در README محصول.

**C7 آرشیو:** Doc Writer (T-076)

۴ ساعت دارد؛ Consultant امنیتی در C4 الزاماً شرکت می‌کند.
