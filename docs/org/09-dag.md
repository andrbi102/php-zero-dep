# گراف وابستگی وظایف (DAG)

> نسخه مهارت: **0.0.2** | اعتبارسنجی چرخه: Graph::hasCycle (scaffolds/graph.php)

## DAG چیست و چرا مهم است؟

DAG (گراف جهت‌دار بی‌چرخه) یعنی: هر وظیفه فقط بعد از پیش‌نیازهایش شروع
می‌شود و هیچ دو وظیفه‌ای نیست که «منتظر هم» باشند. اگر چرخه پیدا شود،
پروژه در بن‌بست می‌ماند: A منتظر B و B منتظر A. قاعده ۴ AGENTS.md اجرای
DAG بدون چرخه را الزامی می‌کند و `Graph::hasCycle()` ابزار ماشینیِ بررسی است.

## گراف نمونه (پروژه معمول)

```
F1 → T-010-01 → T-010-02 → T-000-01 → T-010-03
                                      ├─ T-048-01..03 (Autoloader)
                                      ├─ T-049-01..04 (Router)
                                      └─ T-050-01..04 (DI)

F1 → T-011-01 → T-011-10 → T-001-02 (Veto — شرطی)
F1 → T-014-01 → T-014-02 → T-020-01 → T-061-01
F1 → T-017-01 → T-040-01 → T-064-01..04

F4 → F5 (T-074-01) → F6 (T-012-03..07) → F7 (T-011-02..09)
  → F8 (T-076-01..03) → F9 (T-005-01..04) → F10 (T-005-05)
```

## چگونه بخوانیم

- **پیکان = «بعد از»:** `T-010-01 → T-010-02` یعنی وظیفه دوم فقط بعد از اتمام اولی.
- **شاخه‌های موازی (`├─`):** بعد از `T-000-01` (تأیید معماری)، Autoloader و
  Router و DI **موازی** پیش می‌روند — در solo تا سقف ۷ Worker هم‌زمان.
- **`T-001-02 (Veto — شرطی)`:** یالِ گارد امنیتی؛ اگر وتو شود، مسیر متوقف
  و بازطراحی می‌شود (وتوی مطلق، `06-council.md`).
- **زنجیره فازها:** F4 تا F10 ترتیبی‌اند — بازبینی قبل از تست، تست قبل از
  بازبینی امنیتی، … ، انتشار آخر.

## قواعد

- DAG بدون چرخه؛ وظایف سطح ۰ ریشه؛ وظایف سطح ۴ برگ.
- پیش از هر انتشار، DAG با `Graph::hasCycle()` اعتبارسنجی شود (قاعده ۴ AGENTS.md).

## نمونه تخلف و کشف آن

**تخلف:** `T-049-01` (تعریف مسیرها) به `T-050-01` (اتصال DI) وابسته
شود، درحالی‌که `T-050-01` هم برای نمونه‌سازی کنترلر به `T-049-01`
نیاز دارد — چرخه کامل.

**کشف:** `php -r 'require "scaffolds/graph.php"; …'` با افزودن یال‌ها؛
`hasCycle()` مقدار true برمی‌گرداند؛ انتشار تا اصلاح متوقف می‌شود.

**اصلاح:** وابستگی واقعی را بازبینی کن — معمولاً یکی از دو یال، وابستگی
«به خروجی» نیست بلکه به «قرارداد/اینترفیس» است؛ اینترفیس را در فاز F2
ثابت کن و چرخه باز می‌شود (ثبت در ADR).

## نکته‌های اجرایی

- **پیش‌نیاز، خروجی است نه حضور:** «فاز X تمام شد» یعنی artifacts آن فاز
  DoD گرفته‌اند، نه فقط تقویمِ آن گذشته.
- **یال اضافه = کندی بی‌دلیل:** فقط وابستگی واقعی را ثبت کن؛ موازی‌سازیِ
  مجاز (شاخه‌های `├─`) سرعت است.
- **DAG زنده است:** هر افزودن/تغییر وظیفه، گراف را به‌روز کن و پیش از
  انتشار دوباره `hasCycle()` بگیر.
