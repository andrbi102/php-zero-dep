# استراتژی کش

لایه‌ها: ۱) OPcache (بایت‌کد)؛ ۲) کش در حافظه پردازش (array)؛
۳) کش فایل‌محور `scaffolds/cache.php` با TTL و قفل stampede؛
۴) کش کوئری با کلید پایدار (sha256 sql+params).
قاعده invalidation صریح: هرنوشتنِ داده، کلیدهای مرتبط را invalidate کند —
کش بدون سیاست انقضا = باگ آینده.

### ✅ Checklist

- [ ] TTL برای همه کلیدها
- [ ] قفل stampede روی محاسبه سنگین
- [ ] invalidate صریح پس از نوشتن

### ❌ Anti-patterns
- کش بی‌انقضا برای داده متغیر
- کلید کش وابسته به ترتیب پارامتر
