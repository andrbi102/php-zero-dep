# بنچمارک و ادعاهای عددی

قاعده صداقت (SPEC): ادعاهای عددی (latency، req/s) فقط با برچسب
«خوداظهاری» یا بنچمارک مستقل قابل بازتولید بمانند. نمونه: ادعای
NexusPHP (<3.5ms) خوداظهاری README است — در خروجی مهارت با برچسب
بیاورید. بنچمارک خودتان: ab/wrk + اسکریپت بار، با نسخه PHP و تنظیمات
ثبت‌شده در گزارش F6 (Performance Lead T-013).

### ✅ Checklist

- [ ] هر عدد با منبع (خوداظهاری/اندازه‌گیری)
- [ ] شرایط بنچمارک (نسخه، سخت‌افزار، بار) ثبت
- [ ] مقایسه فقط با شرایط برابر

### ❌ Anti-patterns
- انتقال عدد بنچمارک دیگران بدون برچسب
- میانگین گرفتن از latency بدون توزیع (p95/p99)
