# CSRF در رابط کاربری

توکن در فرم‌های POST و در هدر X-CSRF-Token برای درخواست‌های fetch؛
چرخش توکن پس از login (بازنشانی نشست). پیام خطای 419/403 قابل فهم
برای کاربر با لینک «تلاش دوباره» که فرم را بازتولید و توکن تازه می‌سازد.

### ✅ Checklist

- [ ] هدر X-CSRF-Token در fetchهای AJAX
- [ ] خطای CSRF با UX بازیابی (نه صفحه سفید)

### ❌ Anti-patterns
- توکن در URL یا query string
