# کامپوننت‌های UI سبک

رویکرد: کامپوننت PHP ساده (متد/فایل قالب) + Alpine.js برای
جزایر تعاملی — مرجع: **Hot-UI** (hot-ui/hot-ui در Packagist —
PHP 8.2+، Zero-dependency، Alpine islands) و الگوی Blink.
بدون build step: CSS/JS به‌صورت فایل استاتیک با نسخه در نام.
