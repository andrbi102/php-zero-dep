# دسترس‌پذیری (A11y)

کنتراست ≥ 4.5:1 متن معمولی؛ ناوبری کامل با کیبورد (focus visible)؛
alt معنادار؛ aria فقط وقتی HTML معنایی کافی نیست (Accessibility
Specialist T-034). تست: صفحه‌خوان (NVDA/VoiceOver) + لینوتِس تست
دستی چون ابزار خودکار فقط بخشی را می‌گیرد.

### ✅ Checklist

- [ ] HTML معنایی پیش از ARIA
- [ ] focus قابل مشاهده
- [ ] تست کیبورد در چک‌لیست F6

### ❌ Anti-patterns
- div با onclick به‌جای button
- aria-label بدون متن واقعی
